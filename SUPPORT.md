# Support

Ledgerly is an open-source project maintained on a best-effort basis. Choose the
channel that matches your request so maintainers and contributors can respond
effectively.

## Questions and troubleshooting

Use [GitHub Discussions](https://github.com/d4rkNinja/ledgerly-app/discussions)
for installation help, usage questions, troubleshooting, and early-stage ideas.
Include relevant versions, environment details, and sanitized logs.

## Bugs and feature proposals

Use the [issue forms](https://github.com/d4rkNinja/ledgerly-app/issues/new/choose)
for reproducible defects and scoped feature proposals. Search existing Issues
first and provide enough information for someone else to understand the problem.

## Security vulnerabilities

Use
[GitHub private vulnerability reporting](https://github.com/d4rkNinja/ledgerly-app/security/advisories/new)
and follow [SECURITY.md](SECURITY.md). Never disclose a suspected vulnerability
or exposed secret in an Issue or Discussion.

## Privacy

Do not publish credentials, tokens, personal financial data, production records,
private database contents, or unredacted logs and screenshots. Replace sensitive
values with clearly marked examples before sharing diagnostic information.

Support is provided without guaranteed response or resolution times.
