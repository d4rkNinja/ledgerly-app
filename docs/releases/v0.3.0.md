# Ledgerly v0.3.0 — Quiet Ledger

Released 2026-08-27.

Ledgerly v0.3.0 introduces the Quiet Ledger interface: a calmer, denser, and
more deliberate experience for personal, family, and team finance. The
existing Ledgerly logo is unchanged.

## Highlights

### A complete interface polish

- A cohesive light and dark token system now governs canvas, surfaces, ink,
  borders, financial states, elevation, spacing, and shape.
- Manrope is used consistently across navigation, controls, headings, body
  copy, and financial values; amounts and dates use tabular numerals.
- Desktop navigation, mobile dock, authentication pages, finance surfaces,
  dialogs, forms, and dense record lists were rebalanced for clearer hierarchy
  and less decorative card treatment.
- Mobile layouts respect safe areas and dynamic viewports, with usable touch
  targets and single-column fallbacks where compression would harm readability.

### Motion that explains state

- Bottom sheets open in 280 ms and close in 220 ms, with shorter scrim fades.
- Copy/check feedback and destructive confirmation changes use restrained
  140–180 ms opacity and transform transitions.
- Buttons, checkboxes, switches, and selects settle faster without exaggerated
  bounce, blur, or ripple effects.
- Frequent route headers, sections, navigation, and keyboard-driven actions no
  longer animate simply for decoration.

### Accessibility and interaction fixes

- Bottom-sheet backdrops are no longer duplicate keyboard stops, and closing a
  sheet restores focus to its opener.
- Destructive confirmations move focus to the safe action and back to their
  trigger when cancelled; final actions have distinct confirmation labels.
- Copy completion is exposed through atomic polite live regions in addition to
  the visible icon state.
- Reduced-motion mode removes spatial dragging and other nonessential movement.

### Reporting and deployment

- Insights can now select a bounded reporting period and compare it with the
  previous equivalent period.
- A self-hosted Docker Compose stack builds and runs MongoDB, the Go API, and
  the nginx-served web client together.
- GitHub Actions now checks API formatting, vetting, tests, and builds alongside
  the complete web validation pipeline.

## Brand and native surfaces

- The fixed-logo Quiet Ledger system is documented in
  `docs/ledgerly-brand-system.md` with a visual reference board.
- Browser theme colors, Capacitor backgrounds, Android splash screens, launcher
  assets, and the Play Store icon share the same launch canvas colors.
- `web/public/logo.svg` remains unchanged.

## Verification

- Frontend: 62 test files and 388 tests passed; typecheck, lint, and production
  build passed.
- Backend: `go vet ./...`, `go test ./...`, and `go build ./...` passed with
  the repository-pinned Go 1.26.5 toolchain.
- Android: all 74 script contract tests passed; Gradle dependency resolution,
  debug unit tests, and debug lint completed successfully.
- Browser QA covered desktop and 390 × 844 mobile layouts, quick add,
  validation, transaction creation, copy feedback, destructive confirmation,
  keyboard focus, and real reduced-motion emulation.

## Upgrade notes

- No data migration is required for the UI, Insights, or deployment changes.
- Android launch assets were regenerated from the existing fixed Ledgerly mark;
  native package versioning remains independent of the web release version.
